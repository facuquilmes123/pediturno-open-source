# Guía de Contribución (Contributing)

¡Gracias por tu interés en mejorar **Pediturno Open-Source**!

## Cómo contribuir

1. Hacé un **Fork** del repositorio.
2. Creá una rama para tu funcionalidad o corrección (`git checkout -b feat/mi-mejora`).
3. Asegurate de no incluir credenciales reales ni archivos `.env` o `google-services.json` reales.
4. Ejecutá la suite de pruebas (`npm test`) y el chequeo de tipos (`npm run typecheck`).
5. Abrí un **Pull Request** describiendo claramente los cambios.
